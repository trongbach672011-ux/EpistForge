# Implementation Plan: Multi-Agent Research Tool MVP

## Overview

Implement the protocol in `SPEC.md` and the hard invariants in `RULES.md` as a local Python research tool. The tool will expose the same validated workflow through a CLI and an MCP stdio server so Codex, Claude Code, Kiro, Kilo Code, and Hermes can use it as a shared evidence/provenance boundary.

## Architecture Decisions

- Python 3.11+ package with Pydantic models for explicit validation and machine-readable schemas.
- Filesystem-backed append-only storage. Raw artifacts are never overwritten; derived objects keep input IDs and hashes.
- CLI and MCP are thin adapters over one core service. No client-specific scientific logic.
- External agents remain responsible for research/model calls. The tool enforces roles, phases, state transitions, blind-verifier context, evidence chains, and completion gates.
- Local stdio MCP is the default integration because all requested clients support local MCP servers. Streamable HTTP is documented as a future deployment path, not silently claimed as implemented.
- No database, cloud credentials, or automatic experiment execution in MVP. Experiment execution is registered and recorded through explicit artifacts.

## Risks and Mitigations

| Risk | Impact | Mitigation |
|---|---|---|
| Concurrent agents write the same project | High | Atomic create-only writes, explicit round lock, and role/phase checks |
| MCP clients differ in config syntax | Medium | One stdio server plus verified per-client snippets |
| Verifier sees producer narrative | High | Separate producer conclusion storage and a blind context API |
| Raw result is overwritten | High | Content-addressed manifest and create-only artifact paths |
| Tool is mistaken for a scientific truth oracle | High | Status/gates preserve `DISPUTED`, `INCONCLUSIVE`, limitations, and uncertainty |

## Open Questions / Explicit MVP Limits

- External web search is not bundled. Researcher and novelty agents must bring source URLs and query logs; a future connector can add retrieval.
- Experiment runner does not execute arbitrary code. It records externally produced raw outputs and environment metadata.
- GitHub publishing requires a user-provided remote/repository. Local Git history can be created now; pushing is only possible after a remote is available.
